# Header navigation states

The current destination is a non-link pill that follows the route. The pill uses the theme foreground for its fill and the theme background for its text. Off-route links stay plain until hover or keyboard focus. Both states add a translucent pill, with an outline for keyboard focus.

Chrome captures use a disposable signed-in fixture with a recording detail route selected.
