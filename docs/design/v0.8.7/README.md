# Resolution release configurations

A release group can contain MusicBrainz editions with the same musical program. Resolution shows one choice per verified configuration and puts individual MBIDs and edition metadata in a disclosure. It groups exact ordered recording MBIDs, medium and track positions, and known mix information. The representative is selected from eligible editions using verified chronology, an existing matching source when available, territory evidence, and a deterministic tie-break. The chosen program is stored in the existing canonical album and tracklist, with all equivalent source IDs marked in the retained verification evidence. Individual listening edition attribution remains unknown.

## Disposable acceptance

- Crash uses the 21 checked edition tracklists retained in production assessment 321. Sixteen editions share the same standard 12-track program. The Atmos program and four expanded editions have separate evidence.
- Heartland uses the retained 2012 tracklist and the checked 1980 UK album and 2001 reissue. The original 11-track program contains studio Heartland at track 2. The 2001 edition adds live tracks; those additions do not become canonical memberships automatically.
- Production assessment data was read only. Disposable observations use fabricated timestamps. Requests verify one album is admitted atomically with the recording and the unchanged source observations. The shared Chromium scenario runs against a sealed artifact with disposable native Auth.
