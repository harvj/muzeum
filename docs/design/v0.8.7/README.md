# Resolution release configurations

A release group can contain MusicBrainz editions with the same musical program. Resolution shows one choice per verified configuration and puts individual MBIDs and edition metadata in a disclosure. It groups exact ordered recording MBIDs, medium and track positions, and known mix information. The representative is selected from eligible editions using verified chronology, an existing matching source when available, territory evidence, and a deterministic tie-break. The chosen program is stored in the existing canonical album and tracklist, with all equivalent source IDs marked in the retained verification evidence. Individual listening edition attribution remains unknown.
