# Entity pages and listening history

Captured in Chrome using a disposable Charli xcx catalog and resolved listening fixtures. Each view shows the 30-day period grouped by day, with Details collapsed. Missing days keep their calendar slots. Desktop charts run oldest to newest from left to right. Mobile charts run newest to oldest from top to bottom and scroll within the card.
