# Catalog, Resolution, and Archive polish

Artists and Releases start with search and sort by estimated listening time. Zero-play entries remain visible, and the comparison bars use neutral colors. Each observation contributes once per release, even when that release contains the recording more than once. Releases remain in the catalog index regardless of ranking preferences.

Recording Resolution uses the same muted section headings as the entity pages, a neutral Unresolved badge, a green Resolved badge, and a dark confirmation button with a green check. On an entity page, the expanded listening history uses the effective musical palette for its period bars.

Archive starts with search and listening history. The compact column beside Length shows the resolved recording's effective musical colors. Clear search returns to the unfiltered view.

Chrome captures use local fixtures at 1440 × 960 on desktop and 390 × 844 on mobile.
