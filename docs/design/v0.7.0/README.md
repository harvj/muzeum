# Musical collections and investigation

Chrome captures use disposable data and retained MusicBrainz fixtures. The investigation views use recorded Solid Queue executions and color only the active state. The Guilt Show views preserve the 13-track base and show the Japanese-edition track’s three resolved plays with the checkbox unchecked and checked. On mobile, the additional-track table scrolls horizontally to expose source IDs, durations, and counts.
