# Muzeum Application Shell v1.1.0

Auth PR #5 commit `370aefebd98b53ed3d750b51445d1eaf47a1f042` defines username and eligibility evidence. The Rails endpoint discovers introspection through Auth's validated OAuth authorization-server metadata and uses the current session's confidential refresh grant handle. It checks the verified local subject, issuer, exact client audience, grant digest, evidence lifetime and username schema. The page's opaque binding binds its requests to the same local session. Evidence is never persisted. The disclosure drops links on request error and refreshes on opening, browser restoration and expiry. The destinations remain responsible for their own access control.

The signed Infrastructure v1.1.0 bootstrap is vendored byte-for-byte as encoded payloads. The runtime verifies the publisher signature and complete manifest digests before exposing the registry. A Solid Queue refresh verifies publication freshness asynchronously and atomically persists the highest verified sequence under shared storage. Registry renewals reuse validated payload bytes when the manifest digest is unchanged. The last verified registry survives expiry and publisher outage. It never extends the Auth eligibility window.
