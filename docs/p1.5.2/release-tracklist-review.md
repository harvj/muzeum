# Release-tracklist-assisted review

A listener-confirmed recording can open a batch for an admitted release that contains it. The stored edition's ordered recording signature must match its retained MusicBrainz catalog revision and track count. The scope is explicit, one source account and one stored edition. Loading the review does not assign recordings, call a provider, or admit a release.

The review searches literal artist, release and track tuples through the existing exact-surface index. It examines at most 100 stored slots, 200 claim tuples and the 50 most recent matching plays. It displays up to 15 groups. These are bounded review results and do not represent all possible matches in the archive. Large or unverified editions are excluded. The fixture with more than 293,000 observations and 10,000 releases rendered one batch in 65.0 ms on the disposable local database.

Confirmation needs a matching source recording ID or an exact source edition ID with a single eligible recording and no contradictory factors. Title-only and competing matches remain for individual review. A conflicting edition or unrecognized recording ID is excluded. None of this can assign release credit. The listener checks each choice and submits once. An explicit rejection records feedback without assigning anything. An unselected proposal creates no decision. Comments are optional.

The server signs the displayed evidence, listener, release revision, and observation IDs for 20 minutes. Confirmation rechecks the same listener and managed-account grant, the independent anchor, the release signature, and all selected plays under transaction locks. It refuses stale choices or any existing effective assignment and appends per-play decisions only. The snapshot retains the entire ranking for that proposal, source claims and conflicting factors, affected IDs, version, time, independent decision and edition provenance. Batch confirmations cannot become corroborating anchors. Batch snapshots have a separate version and are retained for later offline validation, before any use in learner training.

Existing investigation now looks for an exact MusicBrainz edition locally or uses bounded catalog candidates to locate matching stored release context. An exact locally verified recording ID or an unambiguous checked slot on an exact source edition ID can finish without a provider call. A separate private review-time pass can add two points when another recording on that release has a still-effective independent manual decision in the same listener's account. Shared provider assessments carry catalog data only. The signed review snapshot preserves the private factor after confirmation. The factor is never sufficient by itself to recommend a recording. The deterministic extension uses a distinct scoring version and no learned weights run in a review request.
