# Limestone and onyx environment

Assets: `public/environments/stone/limestone.jpg`, `onyx.jpg`; independent CSS and standalone `preview.html` in the same directory. The Rails layout only adds an inert `aria-hidden` environment element. Appearance and pause controls are focused Stimulus behaviors with no authentication or import dependency. The static texture never translates, scales, scrolls or changes opacity. Only a radial illumination layer moves: a 23-second event loop with approximately six seconds before onset, gradual localized travel/fade, and seven seconds of stillness after it. Reduced motion removes the overlay; pause and tab visibility stop motion. CSS failure leaves a warm limestone/deep charcoal color fallback.

Generated using the built-in imagegen tool, then cropped into material assets with native CoreGraphics; no new application image-processing dependency. Shared typography is the unchanged Auth identity v1 asset and SIL license. Source prompt:

> Use case: photorealistic-natural. Asset type: website environmental texture. Generate one landscape image split into exactly two equal vertical halves with no divider or margins: LEFT half warm pale neutral limestone, RIGHT half deep charcoal-black onyx. Both flat orthographic close-up stationary stone surfaces filling their half, no objects, text, perspective or shadows. Limestone has richly detailed natural pores, tiny mineral grains and subtle warm tonal variation, tactile real stone. Onyx has finely polished stone texture with subtle mineral variation and restrained fine natural veining, dark and low contrast. Restrained fine pixel dithering in rendering while preserving realistic stone, never blocky. Uniform diffuse lighting, no baked bright illumination patches. These halves will be cropped into separate light/dark web backgrounds.

[Desktop light](previews/desktop-light.png), [desktop dark](previews/desktop-dark.png), [mobile light](previews/mobile-light.png), [mobile dark](previews/mobile-dark.png), [mobile session dropdown](previews/mobile-session-menu.png). Screenshots are the real Rails dashboard backed by **three synthetic test observations**, one observed artist, one album and three tracks. They are not production import evidence. Browser tests assert no horizontal overflow at 1440×960 and 390×844, matching 14px card corners, theme switching, private access, dropdown authorization and reduced-motion fallback.

[Light browser recording](previews/light-illumination.webm) and [dark browser recording](previews/dark-illumination.webm) each show 23 seconds at normal speed, including stillness, soft illumination and fade. `script/record_stone.rb` samples actual Chrome rendering at four frames/second and encodes those frames in Chrome using MediaRecorder. No texture/camera animation, particles, artificial shimmer or continuous whole-background motion is introduced.

Chrome decoded both final WebMs successfully at 1280×720, approximately 22.75 seconds each. Representative still and illuminated frames were visually inspected; the onyx illumination is localized and the underlying veining remains stationary.
