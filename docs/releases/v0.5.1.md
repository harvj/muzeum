# v0.5.1 — Site Art and live catalog refresh

- The header and footer sit directly over Site Art. Content cards, tables, and nested reading surfaces use a shared translucent palette in both themes. Text, charts, and controls retain full opacity. Site Art assets, navigation, and the page layout remain unchanged.
- The Canonical in Muzeum panel updates automatically as catalog verification finishes. It links every verified Release that contains the candidate recording, including reused releases. It keeps release verification pending when there is no verified membership and preserves the expanded candidate and recording decision.
- The existing footer publication task writes its nonsecret version marker with runtime-readable, non-writable group permissions on each release.

The locked Puma dependency includes the upstream security fixes for GHSA-4v6q-hvv7-49h9 and GHSA-rhww-p99c-hgj9.

This is a code-only release. The existing minimal Capistrano path stages and promotes the exact candidate, restarts Muzeum web and worker only, and verifies readiness and the changed routes. v0.5.0 at `414b954bfa8baf976585f9ef2b0ed7d873776561` is the compatible application rollback. Scheduled backups and isolated restore verification remain independent.
