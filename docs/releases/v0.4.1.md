# v0.4.1 — Canonical Resolution Context

- Resolution Review shows whether the candidate's artist, recording, and supporting release already exist in Muzeum. Each verified match opens its own catalog page. Confirmation applies the recording to the matching observations and preserves the original Last.fm release text.
- Investigation starts with verified local catalog data and uses established MusicBrainz identities to check related recordings and releases. Last.fm MBIDs are retained as source claims. The review retains the retrieved tracklist and its provenance, highlights exact recording matches, and distinguishes absent recordings from unavailable evidence. A failed or unchecked release can be retried from its candidate. A catalog appearance leaves the played edition unverified.
- Recording enrichment keeps all verified credited artists, their order, credited names, and join phrases. Existing canonical artists are reused.
- The Archive renders original recording and release text in muted italics. Confirmed canonical titles remain upright. Screen readers retain recording status, and hover or keyboard focus reveals the full title when it overflows.
- Navigation keeps its Site Art colors with padded, rounded states for mouse and keyboard use.

No database migration is required.

## Review evidence

Production v0.4.0 had separate catalog rows for Tove Lo, the recording “bad days” and the checked BLUE LIPS edition. The same exact public MusicBrainz identities and actual 14-track release response drive the disposable Chrome test. The test exercises the review UI without changing decisions.

For Lady Wood, production evidence recorded only the Last.fm release claim `0a85f0ea-e752-40e8-a609-d2196f29cef5`, which returned HTTP 404. The old discovery path did not pursue the candidates' concrete supporting editions after that explicit claim. MusicBrainz returned the actual tracklist for candidate edition `5e8e4f11-a4af-4dec-aee0-c9a99a2908ca`, used in the regression test. Production already knew Tove Lo, with no canonical Lady Wood release or Influence recording. Her stored MusicBrainz identity scopes the search. The same MusicBrainz evidence produces identical appearances and ranks with absent, matching, stale, or incorrect Last.fm IDs. The initial investigation permits one fallback beyond the existing edition discovery limit. Additional unchecked candidates can request their exact supporting edition through the existing worker and provider budget.

### Archive italics verification

The Archive loads the genuine DM Sans italic face locally for original recording and release values. The shared Shell font files and synthesis setting are unchanged. The italic font and its SIL Open Font License come from the [pinned upstream DM Sans distribution](https://github.com/google/fonts/tree/db50662ac42c361aa77afeef89ae2e6e2298e2ab/ofl/dmsans).

The Chrome regression compares screenshots of each title against the same title forced upright. It checks unresolved and partially resolved recordings, reported releases, canonical titles, hover, keyboard focus, text selection, and truncation. Removing the italic face rule reproduces the original failure with identical rendered pixels.
